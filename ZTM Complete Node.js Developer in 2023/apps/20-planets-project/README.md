# Planets Project

#1 Create a project folder and name it "planets-project".

#2 Create a README.md file, add project description into it.

#3 Put a kepler_data.csv file into it.

#4 Initialize the project with `npm init` command.

#5 Install "csv-parse" package with `npm install csv-parse` command.

#6 Create index-v1.js file.

#7 Use File System module of the Node.js to read file data.

#8 Create index-v2.js file. Use parse() function of the csv-parse package to parse the row data returned by `fs.createReadStream` function.

#9 Create index-v3.js file. Write a function to find habitable planets and use it
to filter the data.
